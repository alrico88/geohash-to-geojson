# geohash-to-geojson — AGENTS.md

Single-package TS library. Converts geohash strings to GeoJSON.

## Commands (use `pnpm`)

| Command | What |
|---------|------|
| `pnpm test` | vitest run (single pass, no watch) |
| `pnpm run coverage` | vitest run + lcov coverage |
| `pnpm run lint` | `biome check --write` |
| `pnpm run build` | rslib → `dist/index.{js,mjs,d.ts}` |
| `pnpm start` | `rslib build --watch` |
| `pnpm run docs` | typedoc (config in `typedoc.json`) → docs/ |
| `npx tsc --noEmit` | type-check only (tsconfig `noEmit: true`) |

Order: `biome check --write` (fmt + lint) + `tsc` → `test` → `build`.

## Build

- Entrypoint: `src/index.ts` only. All public API re-exported from it.
- rslib produces CJS (`dist/index.js`), ESM (`dist/index.mjs`), types (`dist/index.d.ts`).
- tsc never emits JS — only type-checks (`tsconfig.json`: `noEmit: true`).

## Testing

- vitest v4 (config in `vite.config.ts`).
- Single test file: `tests/index.test.ts`. No `--watch`, no `--ui`.

## Lint & Format

- Biome (`biome check --write`). Config in `biome.json`.
- VCS integration with `.gitignore` via `useIgnoreFile: true`.

## CI

Travis CI on master only. Runs `yarn test` + `yarn run coveralls`. Uses yarn in CI despite local pnpm.

## Structure

```
src/index.ts          ← public API, all exports
src/helpers/
  geohash.ts          ← ngeohash decode wrappers (BBox, centroid)
  geojson.ts          ← GeoJSON factory helpers (polygon, point, featureCollection)
  utils.ts            ← CheapRuler, @turf/circle wrappers
tests/index.test.ts   ← all tests
```

## Notable

- `sideEffects: false` in package.json — tree-shakeable.
- `dist/` in `.gitignore` — built output not committed.
- docs/ dir exists but empty; generated by typedoc.
